## How to run it

1. **Read the manual (Markdown):**
   ```bash
   cat docs/manual/index.md
   # or open docs/manual/*.md in any Markdown viewer
   ```

2. **Use the static site (no install):**
   ```bash
   # Open directly in browser:
   open site/index.html
   # Or serve locally:
   python3 -m http.server 8000 -d site
   # Then visit http://localhost:8000
   ```

3. **Print a template:**
   ```bash
   # Open in browser and press Ctrl+P / Cmd+P
   open templates/printable/printable-complaint.html
   ```

## Known gaps / Future improvements

1. **No automated HTML validation** — only basic structure/link checks. Could add `html5validator` or similar for stricter validation.
2. **No PDF generation** — printable templates rely on browser print-to-PDF. Could add a script using `weasyprint` or `pagedjs-cli` for automated PDF output.
3. **No search** — static site has no client-side search. Could add a small JS search index for larger manuals.
4. **Single CSS file** — `style.css` is embedded in each HTML page via `<link>`. For true offline use, could inline CSS or use a single-page app approach.
5. **Accessibility** — basic skip-link and semantic HTML present, but no full WCAG audit.
6. **Internationalization** — English only.
7. **AI prompt testing** — prompts not tested against specific AI models; user results may vary.
