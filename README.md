# Writing Letters with AI

A beginner-friendly manual for writing letters with AI: complaints, appeals,
thank-you notes, and requests. Step-by-step templates, tone guidance, and what
never to include — plus printable letter templates you can fill in by hand or
on screen.

Written and published by **Asdale Dynamics, LLC** (Indiana, formed October

AI education: plain English, step by step, never condescending. Dylan is a
registered nurse turned AI author and founder of Asdale Dynamics, LLC. His
book *The Massive AI Manual* and hub site dylanasdale.github.io explain AI
"like a friend would."

## What's inside

| Folder | Contents |
|--------|----------|
| `docs/manual/` | The full manual in Markdown: getting started, tone guidance, what never to include, and four letter types with AI prompts |
| `templates/` | Fill-in-the-blank letter templates for complaints, appeals, thank-you notes, and requests |
| `templates/printable/` | Print-ready HTML versions of each template |
| `site/` | A static HTML version of the entire manual (no build step, no server needed) |

## How to use it

1. Read `docs/manual/intro.md` (or open `site/index.html` in your browser)
2. Pick the letter type you need: complaint, appeal, thank-you, or request
3. Follow the step-by-step template, fill in your details, and paste the AI
   prompt into your chat tool of choice
4. Review the result carefully — never send anything you haven't read
5. Print from `templates/printable/` if you need a paper copy

## What you won't find here

No medical advice. No legal advice. No secrets, API keys, or personal data.
This guide is education only. If a letter affects your health, benefits, or
legal rights, have a qualified professional review it before you send it.
